# User Stories

## Poll Creation & Tagging
* **As a** user, **I want to** create a multiple-choice question and set an exact closing time **so that** voting closes automatically.
* **As a** user, **I want to** assign categories and tags (e.g., Sports, Tech) to my poll **so that** other users can easily find it.
* **As a** user, **I want to** filter polls by category **so that** I can focus on topics I am most knowledgeable about.

## Voting, Points & Staking
* **As a** user, **I want to** stake a portion of my points on an answer **so that** I can double my points if I correctly predict the majority.
* **As a** user, **I want to** earn early-bird bonus points **so that** I am rewarded for participating early in the poll lifecycle.
* **As a** user, **I want to** receive an automated summary notification when a poll ends **so that** I know the final result and my updated point balance.

## Daily Challenges
* **As a** user, **I want to** participate in an automated system-generated "Daily Question" **so that** I can compete for double point rewards.

## Social Features & Community
* **As a** user, **I want to** post comments under a poll **so that** I can justify my choice and persuade others to vote the same way.
* **As a** user, **I want to** follow high-accuracy users **so that** I can view their selections and align my votes with theirs.

## Profile, Statistics & Store
* **As a** user, **I want** my public profile to display my overall point balance and accuracy rate (%) **so that** others can gauge my track record.
* **As a** user, **I want to** spend accumulated points on cosmetic perks (custom avatars, colored usernames) **so that** I can customize my profile status.
